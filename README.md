# leaf

Лёгкий self-hosted планировщик с видимой иерархией задач, Гантом и пересчитываемым критическим путём.

**Разработчику или AI-агенту: начать с [START_HERE.md](START_HERE.md).**

Это стартовый комплект репозитория, не готовое приложение. Product source, сервер и Docker-образ будут созданы по [плану реализации](docs/IMPLEMENTATION_PLAN.md).

![Выбранный ориентир главного окна leaf](design/references/01-main-screen.png)

## Принципы

Задачу можно записать без дат. Иерархия присутствует с первого релиза. Расчёты корректны независимо от раскрытых веток. Интерфейс спокойный и лёгкий, близкий по ощущению к выбранному референсу. Данные остаются на собственном сервере; в приложение не встраиваются облачные зависимости или аналитика.

## Служебные проверки

```sh
npm run check:kit
npm run test:kit
```

Команды проверяют комплект, а не ещё не написанное приложение. После S0 здесь должны появиться проверенные команды запуска, тестов и сборки — не раньше.
