# ADR 005 — интерфейс планирования и атомарное редактирование

Дата: 2026-10-07. Статус: принято для S3 в рамках существующих defaults.

## Решение

React/SVG отображает одно серверное расписание и один flattened visible-tree для дерева и Ганта. Календарная геометрия и преобразование жеста в явный TaskPlan отделены от компонентов; клиент не рассчитывает CPM. Видимое окно ограничено периодом, а не всей допустимой длительностью проекта. Новых зависимостей нет.

Команда task.edit объединяет текст/статус и необязательный план в существующей SQLite-транзакции. При явном возврате из done сначала снимается done lock, затем применяется план, затем окончательные поля и статус. Вход в done фиксирует уже обновлённый план. Ошибка любого шага откатывает всё; одна команда имеет одну ревизию, operationId и undo. Старые task.update/task.plan остаются совместимыми; миграция БД не требуется.

Auto move записывает notBefore; resize записывает длительность. Fixed move/resize записывает включительный закреплённый интервал. Геометрический preview не сохраняется и не выдаётся за результат пересчёта. Клавиатура и поля панели доступны как альтернативы. Done и summary не редактируются жестами.

Схема зависимостей показывает только действительные непосредственные FS-рёбра. Локальная фильтрация кандидатов переиспользует domain validation, а сервер повторяет проверку перед записью. Иерархия не создаёт стрелок.

## Проверки

SQLite и HTTP tests проверяют combined edit, rollback, done transitions, idempotency и одну отмену. Client и browser tests проверяют редактор, общие строки, жесты, граф и согласованность с сохранённым серверным расписанием. Только синтетические данные; V1 остаётся незавершённой до S4–S6.
