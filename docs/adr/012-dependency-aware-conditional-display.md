# ADR 012 — условное размещение по графу зависимостей

Дата: 2026-10-08. Решение для [C25/D18](../superpowers/specs/2026-10-08-fs-link-placement-design.md).

## Контекст

C19 рисует incomplete интервалы от собственной даты, группы или today. Независимые полосы без обеих дат перекрывают предшественников, хотя сохранённая FS требует визуального порядка. Использовать условную геометрию в command cascade/CPM нельзя: исходные даты остаются nullable.

## Решение

Чистый dependencyDisplay получает валидированный DAG, реальные проекции и свежие C19 bases. Итеративный топологический проход за O(V+E) переносит только бездатную геометрию после максимального real/conditional окончания incoming predecessors, сохраняя более позднюю base. Calendar helpers обеспечивают включительное окончание и рабочие дни. Display overflow ограничивается крайней датой с clipped=true.

projectExplicitSchedule принимает nullable today, по умолчанию null. Сервер сохраняет прежний read-only анализ без чтения часов. Клиент переиспользует эту projection с project today и полными исходными данными; один memoized map обслуживает рисунок, initial window и reveal до filters/collapse. Server real/summary/CPM остаются authoritative; unavailable full pair определяется по отсутствию подтверждённой real projection, приватный provenance не раскрывается в новом DTO. Shifted schedule.display не становится новой групповой опорой.

## Последствия и альтернативы

Нет схем/миграций, новой модели автопланирования или React scheduler. Условные окончания распространяются только по display-проходу; source cascade C24/C25 использует исключительно достоверные реальные finishes. Смена today пересчитывает геометрию без writes/revision/undo. Сортировка/валидация существующей общей projection сохраняет свою прежнюю сложность; O(V+E) относится к новому display pass.

Переносить source даты бездатной работы означало бы отказаться от C11/C19. Поправлять координаты после видимых rows означало бы зависимость от filter/collapse. Дублировать календарные правила в React означало бы два расходящихся расчёта. Выбран общий domain helper без этих изменений.
