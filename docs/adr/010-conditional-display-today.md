# ADR 010 — общий helper условного отображения и today

Статус: принято по C19, 2026-10-08.

## Контекст

Серверный schedule пересчитывается при mutation, а today меняется без новой ревизии. Сохранение today в исходных полях или operations изменило бы summary/CPM и поведение exact retry.

## Решение

Вынести календарную геометрию условных полос в чистый domain helper. Сервер передаёт собственные сроки/групповую опору и today=null. Клиентское представление передаёт today явно для оставшихся конечных работ и использует тот же helper; React не реализует календарную арифметику. Source, real schedule, summary, FS, coverage и CPM независимы от display. Response DTO и schema version не меняются; task.create получает совместимые необязательные source поля, сохранённые frozen replies не переписываются.

## Последствия

Today-полосы обновляются при смене дня без записи и undo. Серверный display содержит только статические own/group полосы; API не возвращает придуманную текущую дату для задач без опоры. Полные невалидные/недоступные пары не получают fallback. UI default duration=1 передаётся явно при создании, API default остаётся nullable.
