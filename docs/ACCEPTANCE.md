# Приёмка leaf V1

Каждому критерию нужен тест или воспроизводимая ручная проверка с синтетическими данными. Служебный `check:kit` не заменяет ни один application test.

Адаптация C11–C17 имеет отдельные [критерии OS01–OS17](superpowers/specs/2026-10-07-optional-scheduling-design.md) и [принятое нормативное приложение P01–P11/M01–M10](superpowers/specs/2026-10-07-optional-scheduling-policy-proposal.md). O06/G-CPM и G-MIGRATION закрыты решениями C16/C17; implementation и application acceptance ещё впереди. Исторические Auto-числа A08–A09 и соответствующие fixtures остаются примерами S2–S3, а не алгоритмом по явным датам. Полная V1 по C05 требует реализации принятого численного набора и S4–S6; документальное решение не заменяет тестов.

## Дополнительные автоматические свойства

Для целевой модели: исходные nullable поля не заполняются условным display; FS проверяется по реальным границам без автосдвигов; duration и календарная длина согласованы. Summary охватывает всех конечных потомков только при полном интервале, иначе обе даты null. Collapse/filter не меняют реальные данные и knownStartMin группы; одинаковый вход даёт одинаковый результат; undo возвращает исходную проекцию по содержимому (revision может увеличиться); ошибка транзакции ничего не меняет. C16 ready: projectFloat/constraintFloat неотрицательны, constraintFloat<=projectFloat, изменение технической опоры не меняет результат, tight predicate проверяет сами рабочие границы. Incomplete не выдаёт partial за global; infeasible не выдаёт floats/critical sets. C17 stale/missing acknowledgement и failed version insert откатывают весь upgrade. Старые Auto-свойства не являются целевым контрактом.

Для calendar-тестов обязательно проверить конец месяца/года, високосный февраль и даты перехода DST, даже если интерфейс работает только с днями. Для export/import проверить HTML/script как обычный текст, обход путей и ссылки на чужой проект.

## Минимальные наборы тестов после S0

Domain unit + property tests, SQLite integration, API auth/validation/transaction tests, React interaction tests, Playwright E2E и визуальный smoke. `npm test` не должен запускать только kit tests и считаться полным тестированием leaf.

## Компактное рабочее пространство C20

Обязательные критерии CW01–CW08 заданы в [спецификации C20](superpowers/specs/2026-10-08-compact-workspace-design.md): вместимость длинного дерева в двух viewports, отсутствие общей сводки и missing-date warnings, keyboard/focus/dirty forms, сохранённые настройки и undo, локальные FS-конфликты, partial/global labels, меню проекта слева, подписанная отмена в шапке, отсутствие повтора «Задачи» и локальной справки, управление шкалой только при включённом Ганте с постоянно доступным переключателем. Серверные данные и revision не изменяются от действий представления.
