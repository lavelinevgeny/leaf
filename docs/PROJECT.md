# leaf — описание продукта

## Зачем

Пользователь быстро записывает задачи, раскладывает их в дерево, добавляет даты и зависимости только когда нужно, видит план на Ганте и понимает, какие работы определяют срок завершения. leaf должен ощущаться как лёгкий список задач, а не корпоративная система управления проектами.

## Первая версия

| Область | Функции |
|---|---|
| Проекты | Создание, переименование, выбор, архивирование; независимые дерево, календарь и начало планирования. Подтверждение удаления. |
| Задачи | Обязательно только название. Описание, один родитель, порядок, статус, необязательные даты/длительность, связи. |
| Иерархия | Произвольная глубина без искусственного лимита уровней; раскрытие, сворачивание, создание рядом/внутри, перенос ветки, смена уровня. Защита от циклов. |
| Ввод | Быстрое добавление на месте. Enter — соседняя задача; Tab/Shift+Tab — уровень только в режиме редактирования дерева; обычная клавиатурная навигация сохраняется. |
| Гант | Дерево слева, шкала справа, общие строки, масштабы дни/недели/месяцы, сегодня, прокрутка, перемещение/растягивание полос, зависимости. |
| Планировщик | FS-связи, календарь, длительности, автодаты, закреплённые даты, конфликты, неполные цепочки, все критические ветви, резерв времени. |
| Панель | Компактно справа: название, статус, «Детали / Подзадачи / Зависимости». Детали без перехода на отдельную страницу. |
| Зависимости | Предшественники сверху → выбранная задача → последователи снизу. Добавление и удаление связи, переход к задаче и показ на Ганте. |
| Доска | Те же задачи по статусам с сохраняемым контекстом иерархии; перенос между колонками не меняет родителя. Макет ещё не утверждён. |
| Удобство | Поиск, скрытие завершённых, сохранение контекста родителей, автоcохранение с ошибками, отмена действия вместе с последствиями пересчёта. |
| Надёжность | SQLite, миграции, проверяемые экспорт/импорт полного проекта, резервное копирование и восстановление. |
| Доступ | Один локальный пользователь, безопасный вход и сессия; нет регистрации через Интернет и пароля по умолчанию. |

## Вне первой версии

Командная работа, приглашения, роли, чаты/комментарии, несколько исполнителей, метки, произвольные поля, файлы/вложения, отдельные заметки и календарный экран, приоритеты, уведомления, повторения, интеграции, синхронизация с облаками, мобильные приложения, offline-first, тайм-трекинг, план-факт, ресурсы, отдельные календари работников, праздники из внешнего API, другие типы связей и лаги, межпроектные зависимости, зависимости на summary-задачи, AI-функции.

Это ограничения рабочей версии, а не запрет на развитие. Кнопки исключённых функций не показывать как неработающие заглушки. См. DECISIONS для неоднозначностей изображений.

## Главные пользовательские сценарии

**Запись без планирования:** создать проект без даты старта → добавить дерево → закрыть/открыть приложение → всё сохранено; фиктивных сроков нет.

**Планирование:** указать начало проекта, длительности и связи работ → получить даты, сводные интервалы и критический путь → изменить подзадачу → увидеть новые сроки и новую критическую ветвь.

**Редактирование:** выбрать строку → справа детали → поменять длительность → Гант и дерево обновлены одним действием → undo возвращает данные и весь план.

**Неполнота:** работа зависит от задачи без длительности → цепочка помечена как неполная, а не ложно рассчитанная.

**Личный сервер:** собрать контейнер, установить пароль локально, подключить постоянный том, перезапустить и восстановить резервную копию без потери структуры и зависимостей.

## Нефункциональные цели

Основной viewport — 1440×900, дополнительный — 1280×800. При 1024 px не ломать управление: панель может быть overlay, менее важные колонки скрываются. Отдельный мобильный UX не требуется.

Целевой сценарий — до 2 000 конечных работ и 5 000 связей на проект; это **проектная цель, не измеренный предел**. Агент в S5 измеряет полный пересчёт и UI на описанной тестовой машине. Не создавать инфраструктуру «на миллионы задач» заранее.

Производительность не оправдывает неверный CPM, потерю данных, невидимые ошибки сохранения или отсутствие клавиатурного доступа.
