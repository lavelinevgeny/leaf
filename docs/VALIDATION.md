# Проверка стартового комплекта

Дата: **2026-10-06**. Проверен именно комплект для начала разработки, не реализованное приложение leaf. Итоги ниже не являются независимым аудитом безопасности.

## Выполнено локально

Среда: Node **v22.16.0**, npm **10.9.2**, Git. Служебные скрипты не потребовали установки npm-зависимостей. `.nvmrc` рекомендует Node 24 для последующей разработки; эта версия в локальной проверке не использовалась.

| Проверка | Результат |
|---|---|
| `npm run check:kit` | Успешно: 24 основных Markdown-документа, 39 внутренних ссылок, хеши трёх референсов, 10 числовых CPM-примеров, 4 календарных примера. |
| `npm run test:kit` | **14 тестов прошли**, нет пропущенных или упавших. |
| `npm run security:workspace` | Проверен 51 файл, находок по реализованным правилам нет. |
| Синтетическая копия комплекта в новом временном Git-репозитории | Staged, tracked и достижимая история прошли privacy guard; реальные аккаунты и remote не использовались. |
| Git ignore | 14 чувствительных путей игнорируются, 4 необходимых публичных пути не игнорируются. |
| Установка хуков | Явная установка в корне сработала; существующий hooksPath не перезаписывается; вложенное размещение комплекта отклоняется. |
| Отсутствующий Gitleaks | Обёртка и установленный pre-commit hook завершились отказом, а не молчаливым пропуском проверки. |
| JSON / YAML | Синтаксически корректны: 5 JSON-файлов и 2 YAML-файла. Это не проверка исполнения GitHub Actions. |
| UI-референсы | Визуально просмотрены все три. В коллажах оставлены только выбранные варианты. Демонстрационные имена/фото обезличены; PNG metadata и EXIF отсутствуют. Последний коллаж «Подзадачи» не включён. |

Тесты guard проверяют в том числе фактически staged байты при изменившейся рабочей копии, секрет в удалённом историческом файле, неотслеживаемое изменение allowlist, SQLite/WAL, symlink и точное совпадение хеша одобренного бинарного файла. Тестовые репозитории создавались временно на синтетических данных и удалены после проверки.

## Не выполнялось

**Gitleaks не установлен в среде подготовки**, поэтому сканирование его движком не выполнено. Проверен отказ при отсутствии инструмента. Реальная установка и успешные staged/history scans обязательны для S0 до публикации; указание версии в конфигурации не является результатом сканирования.

GitHub workflow не запускался в удалённом репозитории. Доступ к сети для установки инструментов в рабочем контейнере был недоступен. SHA внешних Actions и инструкции проверены по публичной документации, но это не заменяет первый реальный запуск CI владельцем.

Нет результатов сборки приложения, typecheck production-кода, браузерных E2E, Docker build, установки на сервер, load testing, резервного копирования или независимого аудита: соответствующего приложения в комплекте пока нет. Нет оснований заявлять поддержку arm64 или измеренную производительность.

Числовые примеры проверены маленьким служебным проверяющим кодом, **не будущим планировщиком приложения**. S2 должен реализовать отдельный модуль и прогнать эти случаи против него, добавить property-based и интеграционные тесты из ACCEPTANCE.

## Обязательное повторение агентом

На своей среде повторить проверки комплекта, установить Gitleaks из проверенного источника, проверить index/history, включить доступную серверную защиту с разрешения владельца. После S0 добавить настоящие проверки приложения и обновлять [STATUS.md](STATUS.md) только фактически выполненными результатами.

Ни сканеры, ни deny-rules не распознают все личные данные. Сохраняются обязательные ручной review публикации и изоляция от production. В архиве нет `.git`, базы, env с секретами, личных конфигураций агентов или полной переписки.
