# S3 — Гант и управление планом

Дата: 2026-10-07. Объём: S3 из [IMPLEMENTATION_PLAN](../../IMPLEMENTATION_PLAN.md), существующие C05–C08 и defaults D04–D12 из [DECISIONS](../../DECISIONS.md). Рабочие детали ниже не становятся новыми решениями владельца.

## Интерфейс и данные

Использовать три выбранных PNG из [design](../../../design/README.md). Светлый главный экран: проекты слева, общее дерево строк и Гант, компактная панель поверх правого края. Один flattened visible-tree определяет порядок и высоту обеих частей; один вертикальный scroll не допускает рассогласования. Дерево имеет регулируемую ширину, время — собственную горизонтальную прокрутку. SVG и React state достаточны; новых библиотек нет.

Шкала имеет дни, недели, месяцы, переход к сегодняшнему дню в часовом поясе проекта, предыдущий/следующий период. Окно времени ограничено выбранным периодом, чтобы большие допустимые сроки не создавали миллионы SVG-элементов. Полосы строятся только из серверных computed dates. Summary имеет сводную форму и признаки partial/containsCritical; одиночные пользовательские даты — пометки. Задачи без дат не получают полос. Стрелки показывают реальные FS между видимыми конечными работами; скрытые endpoints не заменяются фиктивными связями родителей.

Критичность дополняется текстом, отдельно от статуса. Охват, incomplete, infeasible, deadline и ограничения завершённых/закреплённых задач видны. Предварительный расчёт подписан. Сегодня и выходные — календарное оформление, не данные планировщика.

## Команды и редактирование

Проект: начало, календарь и часовой пояс сохраняются через project.schedule. Детали задачи и её план сохраняются одной task.edit: изменения текста/статуса плюс необязательный TaskPlan. Сервер применяет снятие done lock, план, затем окончательный статус внутри существующей транзакции; одна ревизия и одна отмена. Неправильный план откатывает также текст. Старая task.update и task.plan совместимы.

Режим выбирается явно: Unscheduled хранит пометки, Auto — длительность/notBefore/deadline, Fixed — включительный интервал. Для Auto начало/окончание показываются как рассчитанные, редактирование рассчитанного окончания переводится в длительность чистым календарным helper. Auto → Fixed предлагает текущий вычисленный интервал; Fixed → Auto сохраняет длительность. Удаление планирования — явное действие с объяснением влияния на связанные работы. Summary не получает собственного плана; done требует явного возврата в работу.

Перенос Auto задаёт notBefore, правый resize меняет длительность. Fixed переносит закреплённый интервал; недопустимые границы отклоняются. Pointer gesture даёт локальный геометрический preview и ровно одну команду на отпускание; Escape/cancel ничего не сохраняет. Пересчёт FS/CPM выполняет сервер. Поля панели и клавиатура дают альтернативу pointer gesture. Неуспешный/неопределённый ответ сохраняет черновик и тот же operationId для повтора; stale response не перезаписывает новую ревизию.

## Зависимости

Вкладка показывает непосредственных предшественников сверху, текущую работу в центре и последователей снизу. Каждое ребро имеет отдельную стрелку; цепочки размещения не выдаются за связи. Добавление через направление и поиск допустимых конечных работ того же проекта. Self, duplicate, summary и cycle не выбираются; цикл объясняется названиями задач. Сервер повторно валидирует команду. Удаление удаляет только ребро. Переход к соседу заменяет выбранную задачу, доступен возврат. «Показать на Ганте» раскрывает предков, выбирает строку и нужный период.

## Проверка и границы

Независимые unit fixtures: календарная геометрия/DST/выходные, ограниченное окно, пустые и одиночные даты, summary, критические рёбра. SQLite/API: атомарный task.edit, rollback, done transition, undo и idempotency. React: ввод режимов, ограничения, граф, keyboard, dirty/error/retry. Playwright: реальный T=8 → T=10, смена критической ветви, summary, undo, drag/resize, цикл, unknown/fixed/deadline и сохранность после перезапуска. Синтетические screenshots 1440×900 и 1280×800 просмотреть рядом с референсами; production/private runtime не открывать.

S4 доска/поиск и S5 restore/import/export не входят в S3. V1 не объявляется готовой до релизной приёмки. Push, deployment и публикация не выполняются.
