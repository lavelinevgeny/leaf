# Быстрые действия строки задачи — дизайн

Дата: 2026-10-14. Статус: решение владельца C30 от 2026-10-14. Уточняет [C29](../../DECISIONS.md) и §5.2 [спецификации компактных меню](2026-10-12-journal-menu-ux-design.md) только в части строки дерева задач. Меню записи журнала (§5.3) и компонент `ActionMenu` не меняются.

## 1. Проблемы

| # | Замечание владельца | Причина |
|---|---|---|
| P1 | Меню `⋯` строки выглядит старомодно и прячет всего два полезных действия | «Открыть задачу» дублирует клик по строке; остаются «Добавить запись» и «Добавить подзадачу» — два клика вместо одного |
| P2 | При сдвиге разделителя Ганта влево `⋯` строки не видна | `.task-row` имеет `width: max-content`: название не сжимается, правый край строки с датой и `⋯` уезжает за разделитель в прокручиваемую по горизонтали область `.timeline-tree` |

## 2. Решение

- Пункт «Открыть задачу» удаляется: строку открывает клик, Enter или Space-эквиваленты существующего дерева.
- Меню `⋯` в строке `TaskTree` заменяется двумя иконками без подписи: «Добавить подзадачу» (стрелка вниз-вправо с плюсом) и «Добавить запись» (заметка с карандашом). Доступные имена: `Добавить подзадачу: <название>` и `Добавить запись: <название>`, tooltip — действие и сочетание клавиш для подзадачи (Shift+Enter). Порядок: подзадача, затем запись. «Добавить запись» рендерится только там, где подключён журнал (`onJournal`), как и прежний пункт меню.
- Поведение действий не меняется: подзадача — `onAction('child', task)` и фокус быстрого ввода, как Shift+Enter; запись — `onJournal(task, trigger)`. Кнопка подзадачи `disabled`, когда дерево отключено (несохранённые изменения панели). Click и keydown с кнопок не выбирают строку; Shift+Enter на кнопке не создаёт подзадачу.
- Иконки 28×28 px прижаты к правому краю видимой части строки и **не занимают места в потоке**: они появляются поверх конца строки, а дата строки на это время скрывается (`visibility`, геометрия названия и даты не меняется). Фон накладки совпадает с фоном строки (обычный, hover, выбранная).
- Видимость: hover строки, `focus-within`. На устройствах без hover (`hover: none`) — у выбранной строки и при фокусе. Скрытые иконки не перехватывают нажатия (`pointer-events: none`).
- Резерв места под меню в колонке дат (`--leaf-row-menu-reserve`) удаляется: заголовок «Начало / Окончание» выравнивается по датам с обычным отступом строки.

## 3. Узкая колонка (P2)

- В левой части Ганта и в списке строка занимает ширину колонки (`width: 100%`), название сжимается многоточием (`flex: 1 1 auto; min-width: 0`), дата не сжимается. Полное название остаётся в tooltip.
- Иконки закреплены у правого края колонки (`position: sticky`, нулевая ширина в потоке), поэтому видны и при горизонтальной прокрутке, если очень глубокая вложенность всё же не помещается.
- Минимальная ширина колонки дерева остаётся 300 px (существующее ограничение разделителя).

## 4. Приёмка

| ID | Проверка | Где |
|---|---|---|
| Q01 | Строка содержит кнопки `Добавить подзадачу: <название>` и (с журналом) `Добавить запись: <название>`; нет `Действия задачи:` и меню; нажатие создаёт подзадачу / фокусирует composer задачи; не выбирает строку | jsdom + e2e |
| Q02 | Кнопка подзадачи disabled при отключённом дереве; Shift+Enter на строке создаёт подзадачу | jsdom |
| Q03 | Колонка дерева 300 px в виде «Гант», глубокая строка с длинным названием: при hover обе иконки полностью внутри видимой части колонки и принимают клик (`elementFromPoint`) | e2e |
| Q04 | Hover и focus не меняют rect названия и даты; высота строк 38 px; иконки ≥ 28×28 px | e2e |
| Q05 | Без hover иконки невидимы и не перехватывают клик. Показ у выбранной строки в `hover: none` задан CSS и автоматически не проверяется | e2e |
