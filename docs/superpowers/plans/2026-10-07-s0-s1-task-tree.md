# S0–S1 task tree Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** локально запускаемый leaf с сохраняемым SQLite-деревом и компактной панелью.

**Architecture:** Один package.json; React/Vite SPA и Fastify API одного origin. SQLite commands — транзакционные, ревизионные и обратимые; pure domain не зависит от HTTP/UI/SQL.

**Tech Stack:** TypeScript strict, React, Vite, Fastify, better-sqlite3, Vitest, ESLint, Prettier, React Testing Library, Playwright.

**Spec:** [S0–S1 design](../specs/2026-10-07-s0-s1-task-tree-design.md)

## Global Constraints

- Один TypeScript-пакет, React/Vite, Fastify, better-sqlite3.
- UI-строки по-русски, идентификаторы по-английски.
- Незаполненные даты остаются null.
- Используются только три PNG из design/README, без исключённого коллажа.
- Тесты используют только созданные ими временные synthetic DB и автоматически очищают их.
- Ни ORM, ни дополнительный state framework не нужны.
- Kit/privacy проверки запускаются отдельно.
- Расчёт расписания, длительности, Гант, связи и доска — этапы S2–S4.
- Runtime-каталог задаётся LEAF_DATA_DIR и должен находиться вне agent checkout.
- Никакого push, deployment, release или иных remote changes.
